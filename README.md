# MABA
Paper code for *"On Evaluating the Robustness of Large Vision-Language Models via Untargeted Modality Alignment Breaking Adversarial Attack"*.  
This code is released for anonymous review of our USENIX submission. License and authorship will be updated upon acceptance.  

We additionally provide evaluation scripts and several illustrative adversarial example images for reference.  
The IC and VQA evaluation code is mainly adapted from [Qwen-VL](https://github.com/QwenLM/Qwen-VL).
